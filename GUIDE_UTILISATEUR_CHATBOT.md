# 👥 Guide Utilisateur - Chatbot IA La Tour

## Pour les Utilisateurs de La Tour

---

## 🤖 Qu'est-ce que c'est?

Le **Chatbot IA** est un assistant intelligent intégré à La Tour qui peut répondre à vos questions sur:
- 💻 La programmation (JavaScript, Python, Web, etc.)
- 🔒 La cybersécurité
- 📊 Les données et algorithmes
- 🎓 L'apprentissage et les ressources
- Et bien d'autres sujets!

---

## 📍 Où le trouver?

### 🟢 Si vous êtes connecté:
**Un bouton 🤖 apparaît en bas-droit de l'écran**

### 🔴 Si vous n'êtes pas connecté:
Le bouton ne s'affiche pas (vous devez d'abord vous identifier)

---

## 🚀 Comment l'utiliser?

### Méthode 1: Widget Flottant (Partout sur le site)

```
1. Cherchez le bouton 🤖 en bas-droit
   
2. Cliquez dessus pour ouvrir la fenêtre
   
3. Tapez votre question (ex: "Comment faire une boucle en JavaScript?")
   
4. Appuyez sur Entrée ou cliquez "Envoyer"
   
5. Attendez la réponse (1-5 secondes)
   
6. Continuez la conversation!
```

### Méthode 2: Page Dédiée Chatbot

```
1. Dans le menu, cliquez sur "Chatbot IA"
   
2. Vous accédez à une page complète
   
3. Toute votre conversation est visible
   
4. Posez vos questions dans l'input
   
5. L'historique est conservé même après fermeture
```

## 📖 Fonctionnalités

### ✅ Accès Rapide
- Disponible sur **toutes les pages** du site
- Pas besoin de naviguer vers une page spéciale
- Widget toujours à portée en bas-droit

### ✅ Historique Personnalisé
- Votre conversation est **conservée**
- Fermez et rouvrez le widget: vos messages sont toujours là
- Revenez plus tard: tout est gardé en mémoire

### ✅ Réponses Intelligentes
- L'IA **comprend vos questions**
- Répond avec des explications claires
- Adapte ses réponses à votre niveau

### ✅ Offline Friendly
- Après le chargement initial, fonctionne **sans connexion**
- Vous pouvez discuter même hors ligne!

### ✅ Privé & Sécurisé
- Vos conversations **restent locales** (pas envoyées à un serveur)
- Données **isolées par utilisateur**
- Personne d'autre ne peut voir votre historique

## ⏱️ Vitesse

### Première Visite
- ⏳ **30-60 secondes**: L'IA se charge (normal la première fois)
- Message: "Chargement..." s'affiche
- **Attendez patiemment** 😊

### Visites Suivantes
- 🚀 **Instantané**: L'IA est déjà prêt
- Réponses en **1-5 secondes**

### Chaque Réponse
- 💨 **1-5 secondes**: L'IA pense et écrit sa réponse
- Indicateur "typing..." s'affiche (3 points qui s'animent)

## ❓ Questions Fréquentes

### Q: Pourquoi ça met longtemps la première fois?
**R**: L'IA télécharge un modèle (2.5 GB). C'est normal et une seule fois!

### Q: Mes messages sont envoyés à La Tour?
**R**: Non! Tout reste sur votre ordinateur. C'est complètement privé.

### Q: Si je ferme le site, je perds mes messages?
**R**: Non! Ils sont sauvegardés. Rouvrez le site, vos messages sont là.

### Q: Je peux l'utiliser sur mobile?
**R**: Oui! Ça marche sur téléphone aussi (Chrome ou Edge).

### Q: Et sur Safari?
**R**: Ça marche mais en "mode simulé" (réponses préprogrammées, pas d'IA full).

### Q: Je peux l'utiliser sans être connecté?
**R**: Non, le chatbot est réservé aux utilisateurs connectés.

### Q: Y a-t-il une limite de messages?
**R**: Non, vous pouvez discuter autant que vous voulez!

### Q: Comment effacer mon historique?
**R**: Nettoyez vos données du navigateur (devTools → Application → localStorage)

## 🎨 Interface Expliquée

```
┌─────────────────────────────────────┐
│ 🤖 La Tour Assistant          ✕    │  ← Header avec titre
├─────────────────────────────────────┤
│                                     │
│ 🤖 Bonjour! Comment puis-je...   │  ← Réponses de l'IA
│ Vous: Salut!                       │  ← Vos messages
│                                     │
│ 🤖 Content de te rencontrer!      │
│                                     │
├─────────────────────────────────────┤
│ [Posez votre question...]    [Env] │  ← Input + bouton
└─────────────────────────────────────┘
```

**Couleurs**:
- 🔵 **Bleu clair**: Vos messages (droite)
- ⚪ **Blanc**: Messages de l'IA (gauche)

**Indicateurs**:
- ⏳ "Chargement...": L'IA se charge
- 🤖 "typing...": L'IA réfléchit à la réponse
- ✓ "Envoyer": Bouton pour envoyer

## 🔐 Votre Vie Privée

### ✅ Ce qui est protégé
- Vos questions ne sont jamais envoyées
- Vos réponses restent sur votre ordinateur
- Personne n'a accès à votre historique sauf vous
- L'IA ne vous suit pas d'une page à l'autre

### ⚠️ À savoir
- Si quelqu'un d'autre utilise **votre compte**, il verra **votre historique**
- Si vous changez d'utilisateur, l'historique change aussi
- Le navigateur en incognito n'enregistre pas l'historique

## 🆘 En cas de Problème

### Le widget n'apparaît pas
- ✓ Êtes-vous connecté? (Connectez-vous d'abord)
- ✓ Actualisez la page (F5)
- ✓ Videz le cache du navigateur

### L'IA met très longtemps
- ✓ C'est normal la 1ère fois (30-60s)
- ✓ Attendez sans fermer la page
- ✓ Les fois suivantes: rapide!

### Pas de réponse du tout
- ✓ Vérifiez la console (F12 → Console)
- ✓ Rechargez la page
- ✓ Essayez un navigateur différent

### "WebGPU non disponible"
- ✓ Message normal sur vieux navigateurs
- ✓ Le chatbot fonctionne quand même (en "mode simulé")
- ✓ Mettez à jour Chrome/Firefox pour la version complète
