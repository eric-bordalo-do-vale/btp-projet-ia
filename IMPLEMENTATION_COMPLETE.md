## 💡 POINTS CLÉS

### Comment ça marche?
1. Utilisateur se connecte
2. Bouton 🤖 apparaît
3. Clique pour ouvrir widget
4. Envoie un message
5. WebLLM génère réponse (ou mode simulé)
6. Réponse affichée + sauvegardée
7. Historique persiste
